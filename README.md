## 💼 Ключевые проекты

### 1. A/B-тест маркетинговой механики для ретейлера SkyLenta (Дипломный проект Skypro)
**Роль:** Системный аналитик / Data Analyst
**Задача:** Оценить эффективность пуш-уведомлений по сравнению с баннерами.
* **Системный анализ:** Собрала требования, спроектировала модель данных (ER), описала API для сбора метрик.
* **Анализ данных:** Провела EDA для 55 000+ клиентов, очистила данные, построила визуализации.
* **Статистика:** Применила t-тест и критерий Манна-Уитни. Доказала статистическую значимость роста конверсии (+9.87 п.п.) и среднего чека.
* **Бизнес-результат:** Создала Excel-калькулятор, показавший прирост выручки **+2.38 млн ₽** на 10 000 клиентов.
